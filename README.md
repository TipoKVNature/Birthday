# Маленькое приглашение ♡ — деплой и уведомления

Тёплое PWA-приглашение на свидание (категория «Dating»). Работает как сайт,
устанавливается на iPhone как приложение и отправляет владельцу **push-уведомление**
в момент, когда человек завершает опрос.

## Что в папке (кладём всё это в корень репозитория)

| Файл | Зачем |
|------|-------|
| `index.html` | Само приглашение + логика опроса и отправка `/api/choice` |
| `_worker.js`  | Cloudflare Worker: принимает выбор, шлёт его в ntfy, отдаёт статику |
| `sw.js`       | Service worker: показывает push-уведомление на устройстве владельца |
| `manifest.json` | PWA-манифест (иконка на рабочем столе iPhone) |
| `icon.png`, `icon.svg` | Иконки приложения |

## 1. Выложить на GitHub

Репозиторий уже создан. Убедись, что все файлы выше лежат в **корне** репозитория
(не в подпапке). Затем:

```bash
git add .
git commit -m "Deploy: date invitation PWA"
git branch -M main
git remote set-url origin https://github.com/<твой-логин>/<repo>.git
git push -u origin main --force
```

> ⚠️ **Приватную тему ntfy НЕ коммить!** Она хранится только в переменной окружения
> Cloudflare (`NTFY_TOPIC`). Её нет ни в одном файле — тема генерируется приложением.

## 2. Развернуть на Cloudflare Pages

1. Зайди в свой репозиторий на GitHub → **Settings → Pages and sites → Connect a repository**.
   Выбери **Cloudflare** и авторизуйся (если ещё не подключён).
2. На странице деплоя выбери ветку `main` и нажми **Save / Deploy**.
   Облако будет вида `https://<название>.github.pages.dev`.

### Переменные окружения (Settings → Variables and Secrets)

Добавь **обе** переменные в секцию **Environment variables**:

| Имя переменной | Значение |
|----------------|----------|
| `ASSETS`       | *(оставить пустым)* — автоматически включает отдачу статики Worker'ом |
| `NTFY_TOPIC`   | твоя приватная тема ntfy (см. шаг 3) |

После изменения нажми **Save changes**, затем **Create deployment** для новой версии.

> Почему нужна пустая `ASSETS`: в `_worker.js` всё, что не `/api/*`, отдаётся через
> `env.ASSETS.fetch()`. Без этой переменной Worker не найдёт файлы.

## 3. Установить ntfy на iPhone и подписаться на тему

1. Скачай **ntfy** из [App Store](https://apps.apple.com/app/ntfy/id1625396347).
2. Открой приложение → создай/введи свою **приватную тему** (любая строка, например `my-secret-topic`).
   Это же значение вставь как `NTFY_TOPIC` на Cloudflare (шаг 2).
3. Подпишись на эту тему в приложении — теперь ты получаешь входящие сообщения.

> Альтернатива без приложения: браузер с поддержкой push (Chrome/Edge/Safari) тоже может
> ловить уведомления, но для этого нужно сначала получить подписку устройства. Проще всего — ntfy.

## 4. Проверить, что работает

1. Открой ссылку на iPhone → добавь на главный экран («Поделиться» → «На экран «Домой»»).
2. Пройди опрос до конца: «Да» → выбери дату/время → выбери занятие (Пицца / Кино / Игры / 18+).
3. В приложении **ntfy** должно прийти сообщение **«Выбрали свидание 💌»** с датой, временем и занятием.

## Устранение проблем

- **Уведомление не приходит** → проверь, что `NTFY_TOPIC` в Cloudflare точно совпадает с темой
  в ntfy (регистр важен). Пересобери деплой после правки.
- **Белый экран / 404 на файлах** → не добавлена переменная `ASSETS`.
- **Worker не отвечает на `/api/choice`** → проверь, что файл называется именно `_worker.js`
  в корне и деплой пересобран.
